# Bioassays

This folder contains additional data and scripts related to *Dictyostelium discoideum* development and polyketide metabolite analysis.

- `1_development_data_analysis.ipynb`  
  Quantifies spore production, viability, and plaque size.

- `2a_polyketides_eic_data.py`  
  Extracts extracted ion chromatograms (EICs) for known *pks* gene products.

- `2b_polyketides_data_analysis.ipynb`  
  Visualizes the EIC data generated by `2a_polyketides_eic_data.py`.
